# Open-source boundary

This repository is intentionally a narrow public product.

Published:

- API v1 path and envelope conventions;
- public JSON schema, validation tooling and a reference API proxy;
- bilingual documentation, institution attribution and links to the RiskAtlas service.

Not published:

- complete China-issued measure events, subject records or downloadable snapshots;
- non-China jurisdiction data or cross-jurisdiction entity records;
- production database tables, credentials, access controls, customer data or telemetry;
- internal review notes, parser execution logs, matching evidence, confidence models or unpublished source materials;
- commercial batch-screening, monitoring and multi-jurisdiction API data.

The public package must remain code-and-documentation only. A release may not include `.env` files, API keys, database connection strings, complete JSON/CSV/XML snapshots, source archives, raw crawler responses or internal operational documents.

For institutional information and authorized access, visit [RiskAtlas 全球制裁与出口管制数据平台](https://atlas.scholarforce.ai/). The project is supported by the [中央财经大学国家财经战略研究院](https://nafes.cufe.edu.cn/); the open-source kit is an integration and outreach surface, not a redistribution of the complete database.
